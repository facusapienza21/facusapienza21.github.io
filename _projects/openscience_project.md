I believe that physics and the Earth sciences benefit from open, reproducible and collaborative research, and that data science can help to democratize science.
This shows up in two ways in my work: the software I develop and the courses I teach.

### Software and ecosystems

I contribute to the following open-source libraries and communities:
- **[ODINN-SciML](https://github.com/ODINN-SciML)**: an organization developing glacier models based on Universal Differential Equations in Julia, including [ODINN.jl](https://github.com/ODINN-SciML/ODINN.jl), a SciML glacier evolution model.
- **[SphereUDE.jl](https://github.com/ODINN-SciML/SphereUDE.jl)**: a Julia package for regression on the sphere based on Universal Differential Equations.
- **[NoisyCE.jl](https://github.com/facusapienza21/NoisyCE.jl)**: a Julia package for ordinal pattern statistics of noisy time series.
- **[PolarWandering](https://github.com/PolarWandering)**: a collaboration developing statistical methods for paleomagnetic estimation, including [PaleoSampling](https://polarwandering.github.io/PaleoSampling/).
- **[fermat](https://github.com/Fermat-distance/fermat)**: a Python library for computing Fermat distances.
- **The Julia SciML ecosystem**, on which our differential equation and differentiable programming tools are built.
- **The Jupyter and scientific Python ecosystem**, including the integration of Python tools such as [OGGM](https://oggm.org/) and Xarray with Julia models.

### Teaching

I teach these tools and practices to students and researchers (see [Teaching](/teaching/) for more details):
- **STAT 159/259: Collaborative and Reproducible Data Science** (UC Berkeley, 2022 and 2023). Together with [Fernando Pérez](https://bids.berkeley.edu/people/fernando-perez), we developed a curriculum on GitHub collaboration, good programming practices, the Jupyter ecosystem, packaging and testing scientific software, and automation, with applications to climate science.
- **Datos, Ecuaciones Diferenciales e Inteligencia Artificial** (University of Buenos Aires, 2026). A new course on data, differential equations and AI ([course website](https://facusapienza.org/DM2026-Curso/)).
- **[Machine Learning in Glaciology workshop](https://machine-learning-in-glaciology-workshop.github.io)** (Finse, Norway, 2022, 2023 and 2024). I am part of the organizing team and an instructor for this workshop, which introduces machine learning tools to students and researchers in glacier modelling.
